# NutriApp 🥗

Aplicativo de gerenciamento para nutricionistas, desenvolvido em **Java** como
projeto de estudo. O objetivo é aprender programação orientada a objetos,
versionamento com Git e boas práticas de desenvolvimento, construindo o sistema
de forma incremental.

## 📋 Funcionalidades

- [x] Cadastro de pacientes
- [x] Listagem de pacientes
- [x] Edição e exclusão de pacientes
- [x] Persistência dos dados em arquivo
- [ ] Cadastro e listagem de consultas
- [ ] Registro de refeições
- [ ] Planos alimentares
- [ ] Acompanhamento da evolução do paciente
- [ ] Interface gráfica

## 🛠️ Tecnologias

- Java 
- Maven
- Git e GitHub

## 🚀 Como executar

1. Clone o repositório:
2. Abra o projeto no IntelliJ IDEA.
3. Execute a classe `Main`.

## 📚 Conceitos praticados

Classes e objetos, atributos e métodos, construtores, encapsulamento
(getters e setters), Collections (ArrayList), relacionamento entre objetos,
tratamento de exceções e persistência em arquivos.
